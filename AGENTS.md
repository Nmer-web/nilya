# Project constitution

The non-negotiable rules for this repository live in `.specify/memory/constitution.md`. Read it
before planning or implementing. In short: purchasable products and food are NEW-only; jobs and
services are conditionless and never enter commerce journeys; never fabricate data; the Supabase
schema is the source of truth; Auth/Supabase/Realtime/Stripe are frozen except for explicitly
approved amendments recorded there; typecheck and lint must pass, and a runtime test may only be
claimed if it actually ran.
