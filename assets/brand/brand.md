# Nilya — brand basics

## Colors
- Primary (Nilya Green): `#0F6E56`
- Accent (Nilya Amber): `#EF9F27`
- Ink: `#141413`
- Muted: `#6B6B66`
- Surface: `#FFFFFF`

## Type
Wordmark: Inter Medium (500), lowercase, letter-spacing -2.
Tagline: Inter Regular, uppercase, letter-spacing 8.

## Usage
- Minimum icon size: 24px. Below 32px, drop the tagline from any lockup.
- Clear space around the lockup = height of the icon's corner radius.
- Never recolor the amber dot to green; it is the only accent.
- On dark backgrounds use `nilya-icon-mono.svg` or the icon on `#0F6E56` (it holds on dark).

## Files
- `nilya-icon-1024.svg` — app store / launcher icon
- `nilya-icon-mono.svg` — single-color dark variant
- `nilya-lockup-horizontal.svg` — website header, invoices, email
- `nilya-favicon.svg` — favicon / small UI
